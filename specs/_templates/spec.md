## Criterios de aceptación

Cada criterio es verificable y tiene id estable (no se renumera). Formato: *dado / cuando / entonces*.
Si no se puede automatizar, se agrega `[manual]` y el procedimiento de verificación.

- **AC-1** — Dado <estado inicial>, cuando <acción>, entonces <resultado observable>.
- **AC-2** — Dado ..., cuando ..., entonces ...
